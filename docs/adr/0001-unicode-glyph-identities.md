# 单字参考使用精确Unicode标量身份，而不是ASCII全集

单字参考库扩展到中文、字母、数字、标点和符号，身份以一个可见Unicode标量表示；保存、暂存、配对和等格切图共享DP.Vision的身份规则。补充平面汉字保留完整代理对；不做大小写、全半角或Unicode归一化，防止不同工艺参考被静默合并。空白、控制字符、孤立代理项和组合序列不是独立参考；复杂组合字形需后续单独设计，不以放宽字符串长度伪造支持。

每库/暂存清单限4096个参考和1600万参考像素，保持单图块4–512像素及JSON预算；不是要求收齐Unicode字符表。保留v1格式、序数键和不可变修订，旧英数字字库可继续读取，但旧SDK不能读取新增Unicode条目。标点不再从正式规则质量分割中跳过；绑定字库时缺少标点参考属于未完成的必检，必须NG，不能沿用过去的部分覆盖批准。

本决定只扩展单字参考/规则质量A、制库和显式等格布局，本决定当时不改变逐字符异常模型B的ASCII训练与行几何约束（后续已由[ADR-0003](0003-unicode-character-anomaly-models.md)独立扩展），不接入整图自动文字定位。人工制库仍需独立核对真实良品像素，模型识别正确和切割数量一致都不是外观合格证明。
